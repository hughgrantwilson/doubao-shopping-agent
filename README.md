# doubao-shopping-agent
针对网购跨平台选品、比价耗时、信息分散的痛点，基于豆包大模型与 qwen-agent 框架打造的专属购物智能 Agent，一站式解决购物决策难题。 核心能力: 多平台聚合搜索：一键获取淘宝 / 京东 / 拼多多 / 抖音全平台商品信息  智能全网比价：自动计算优惠券 + 运费，算出最优到手价，帮用户省最多钱 个性化推荐：基于用户画像与购买历史，精准匹配高性价比商品 技术原理：内置意图识别、工具调用、对话记忆模块，自动理解用户需求，智能调度搜索 / 比价 / 推荐工具，无需用户手动操作。支持纯本地部署，开箱即用，提供可交互网页端，无需复杂配置。 让购物决策效率提升 80%，告别跨平台比价的繁琐，帮用户轻松买到最划算的商品。
